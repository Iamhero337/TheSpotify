# TheSpotify 🎧

A powerful, ad-free Android wrapper for the Spotify Web Player that unlocks premium features on free accounts.

## ✨ Features

- **🚫 Zero Ads:** Blocks all audio and visual ads at the network level.
- **🔓 Unlocked Playback:** Pick any song on-demand, unlimited skips, and no shuffle-lock.
- **🔋 Background Play:** Keep the music going even when your screen is locked or the app is in the background.
- **📱 Phone Layout:** Served with a custom User Agent to provide the full Desktop feature set in a mobile-optimized UI.
- **🎨 Modern Splash Screen:** Featuring a clean, dark aesthetic.

## 🚀 How to Install

1. Go to the [Releases](https://github.com/Iamhero337/TheSpotify/releases) page.
2. Download the latest `TheSpotify.apk`.
3. Open the APK on your Android device.
4. If prompted, allow "Install from unknown sources" for your browser/file manager.
5. Launch the app and log in with your normal Spotify account.
